Как это сделано, без магии

  1. Разбор вопроса. Из живого текста достаём услугу, тираж, срочность и телефон. Синонимы, числа словами, «2 тысячи», «5 тыс».
  2. Расчёт по прайсу. Цена берётся из каталога, скидка от объёма и наценка за срочность считаются кодом, а не моделью.
  3. Диалог. Бот спрашивает только то, чего не хватает для сметы, и не задаёт вопросов ради вопросов.
  4. Заявка. Телефон падает в базу, диалог сохраняется целиком, выгрузка в CSV одной ссылкой.
Нейросеть здесь не нужна: вопрос узкий, ответ проверяемый. Поэтому бот не выдумывает цены и работает даже когда интернет упал.
# app/pricing.py: скидка от объёма и срочность
def tier_for(service, qty, niche):
    best = 1.0
    for edge in sorted(niche.unit_tiers):
        if qty >= edge:
            best = niche.unit_tiers[edge]
    return best

Что можно проверить прямо сейчас

Смета по прайсу

Спросите «визитки 5000» и «визитки 5000 срочно». Цена изменится по правилам, а не случайно.

Честное незнание

Спросите то, чего нет в прайсе. Бот скажет, что уточнит администратор, вместо выдуманной цифры.

Заявка в базу

Оставьте телефон в демо и откройте раздел «Заявки». Он появится там сразу, с текстом диалога.

Тесты

Правила расчёта и разбор вопросов покрыты pytest. Отчёт по тестам отдаётся по запросу.
